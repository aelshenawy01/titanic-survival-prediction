Titanic Survival Prediction
Machine Learning Classification Project

Goal
Predict whether a Titanic passenger survived based on
demographic and travel information.

Model
Random Forest Classifier

Tech Stack
Python
Pandas
NumPy
Scikit-learn
Matplotlib
Seaborn

Data preprocessing
• Missing-value imputation
• One-hot encoding
• Feature scaling
• Stratified train/test splitting

Model optimization
• GridSearchCV
• 5-fold Stratified Cross Validation
• 12 hyperparameter combinations
• 60 model fits

Results
Test Accuracy: ~82%

Survivor class:
Precision: 79%
Recall: 71%
F1-score: 75%
